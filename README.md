## ما الجديد في 0.5

- أيقونة تطبيق جديدة تظهر المصحف مفتوحًا على حامل القراءة داخل قوس إسلامي وزخرفة هادئة، بصيغ PNG متعددة الدقة ومصدر SVG قابل للتحرير (`design_reference/NEW_QURAN_LOGO_v0.5.svg`). تم تحديث `AndroidManifest.xml` لاستعمال `@mipmap/ic_launcher` بدل الأيقونة القديمة.
- تحسين حساب أسطر القراءة آليًا على حسب العرض والارتفاع الفعليين. في صفحات المصحف المزدحمة (مثل 6 و19 و30 و37)، يصغّر الخط ويضبط عدد السطور المناسب حتى لا يقطع أي نص. إذا تعذرت الملاءمة في جهاز مختلف، يستخدم عرضًا قابلًا للتمرير بدل قص الآيات.
- ضبط الحجم البصري لأرقام الآيات داخل الوردة: رقم واحد، رقمان وثلاثة أرقام بأحجام متدرجة.
- ظهور **رمز الربع** عند الآية التي يبدأ عندها الربع، مع وصف بداية الربع في عنوان التلميح؛ ويظهر نص بداية الربع في وضع القراءة المرنة.
- إصلاح تباين ألوان عناصر التنقل والخدمات والأزرار في الوضع الليلي.
- إخفاء شريط الحالة العلوي لأندرويد (الساعة والواي فاي والبطارية) أثناء عرض التطبيق، مع الإبقاء على وسائل تنقل أندرويد.
- **مشغل التلاوة يظل مخفيًا حتى اختيار «استماع»**. والشريط السفلي بأقسامه الخمسة يبقى ظاهرًا.
- ملف Actions كامل داخل `.github/workflows/build-apk.yml` يتضمن Android SDK v4 وGradle 8.11.1 وJava 17 ورفع `app-debug.apk` ضمن GitHub Artifacts.

- `.github/workflows/build-apk.yml` — بناء APK عبر GitHub Actions.

- `tools/qa_integrity_v05.py` — اختبار مصداقية نطاقات السور/الآيات/الصفحات والأرباع والمصدر الثابت، دون ادعاء شهادة اعتماد رسمية.
- `Preview_Offline_v0.5.html` — معاينة تفاعلية بدون إنترنت (التلاوة تحتاج اتصالًا أو ملفات سبق تنزيلها داخل APK).
- `QA_RESULTS_v0.5.md` — نتائج الاختبار والقيود المعروفة.

## بناء APK باستخدام GitHub

1. **فك ضغط الحزمة أولًا**. ارفع **محتويات مجلد المشروع** إلى جذر المستودع؛ لا ترفع ملف ZIP وحده على أنه التطبيق. يجب أن تجد `app/` و`build.gradle.kts` و`.github/workflows/build-apk.yml` في المستوى الأعلى.
2. ادفع التغييرات إلى فرع `main` (باستخدام Git أو رفع الملفات من الويب مع الحفاظ على المسارات).
3. افتح **Actions → Build Quran Android APK** واختر **Run workflow** إذا لم يبدأ تلقائيًا.
4. عند نجاحه افتح العملية المكتملة → **Artifacts** → نزّل `MadinaQuran-debug-APK`، وفك الضغط وثبّت `app-debug.apk` على الهاتف.
5. عند ظهور فشل، اقرأ أول خطوة حمراء، واحتفظ بملف السجل. اجتياز اختبارات النص/العرض **لا يؤكد** بناء APK أو عمله على هاتف فعلي.

- فحصنا 604 صفحة عند مقاس **390×844**: لا قص ظاهر للأسطر، وتوافق فواصل الآيات والأرباع مع البيانات المخزنة. تم أيضًا فحص صفحات ممثلة على 360×780 و412×915.
