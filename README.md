## التغيير الحاسم في v0.7

لم يعد وضع **مصحف المدينة الأصلي** يعيد صفّ الآيات باستخدام HTML/CSS أو يحاول ضبط الكلمات آليًا؛ يعرض صورة الصفحة المأخوذة **من ملف متجهي أصلي كامل للصفحة**، بعد تحويله دون تعديل النص أو الحركات أو علامات الوقف. بذلك لا تنتج الفجوات والمسافات المصطنعة التي ظهرت في النسخ السابقة. وضع **القراءة المرنة** باقٍ، ويعمل بنص الآيات المحلي.

- **الصفحات الـ604**: تُجهّز كملفات WebP أثناء بناء APK على GitHub Actions من أرشيف نسخة حفص 1439 المتجهية لمجمع الملك فهد. مصدر التنزيل الذي يستخدمه البناء هو **نسخة مرآة مثبتة برقم Commit**، لا ملفًا محررًا أو صورًا مولّدة، وتُفحص سلامة وجود 604 صفحة بعد التحويل. المصدر الرسمي وحقوق الاستعمال موضحان أدناه.
- **الواجهة**: نفس الهيدر الإسلامي المضغوط، الفهرس والعلامات والمتابعة والإعدادات وشريط التنقل السفلي. شريط الاستماع مخفي حتى طلب الاستماع.
- **الآيات التفاعلية**: النقر على صفحة المصحف يفتح **قائمة آيات هذه الصفحة**؛ اختيار آية منها يتيح الاستماع وحفظ العلامة والنسخ. لم ندّع وجود إحداثيات لمس دقيقة على حروف كل آية؛ هذه خاصية تحتاج خرائط مواقع مُراجعة مستقلة حتى لا تختار آية خاطئة.
- **التلاوات**: المنشاوي (افتراضيًا)، الحصري، السديس، مشاري العفاسي، سعد الغامدي، ماهر المعيقلي، علي جابر (سبعة قارئين بملفات منفصلة آية آية لدى EveryAyah)، وعبد الولي الأركاني (سورة كاملة من MP3Quran). يمكن تنزيل السورة أو تشغيلها عبر الإنترنت. التسجيلات لا تتضمنها حزمة المصدر ولا APK تلقائيًا.
- **الخصوصية**: العلامات المرجعية وموضع القراءة والمفضلة محلية في بيانات التطبيق.
- **التحديثات**: توقيع Release بمفتاح JKS المملوك لصاحب المشروع، مستعاد من GitHub Secrets. **لا يتم توليد Keystore تلقائيًا**. الهوية `com.mahmoudelgamsy.madinaquran` لا تتغير. راجع `SIGNING_SETUP_AR.md` للاحتفاظ بالمفتاح الأصلي.

## المصدر المحرَّر والنسخة الأصلية

الجهة الناشرة للنسخة الأصلية: **مجمع الملك فهد لطباعة المصحف الشريف** — [المصحف المتجهي](https://dm.qurancomplex.gov.sa/) — [حقوق الاستخدام](https://dm.qurancomplex.gov.sa/rights/). الموقع الرسمي يعلن بصمة SHA-256 لأرشيف حفص: `280C5D71CA16AAEEB3A343BE1B92C76FA6DF71D0671E202C026FDE12402D9EEF`؛ هذه بصمة **أرشيف التنزيل الرسمي**، وليست بصمة مستودع GitHub المعاد نشره.

المستودع المستخدم آليًا في البناء: [MushafAlMadinahVector](https://github.com/MushafAlMadinahVector/MushafAlMadinahVector) عند المراجعة `a6f52f8b05fa28cdffb637cbbab0ed30515bbeb2`، ملف واحد لكل صفحة `001___Hafs39__DM.ai` إلى `604___Hafs39__DM.ai`. هذا **أرشيف مرآة وليس خادم المجمع**؛ الالتزام برقم المراجعة يمنع تحديث ملفات المصحف دون مراجعة. النسخة الأصلية ومتطلبات استخدامها ليست ترخيصًا مفتوح المصدر بالمعنى التقليدي.

**قبل النشر للجمهور:** ينبغي تأكيد مصدر صفحات المرآة ومطابقتها للنسخة الرسمية، وإجراء مراجعة مستقلة لمظهر الآيات والوقف والتشكيل لكل الصفحات بعد التحويل؛ مجرد اجتياز اختبار عدد الملفات لا يُعد اعتمادًا شرعيًا أو مصحفيًا.

## كيف تحصل على APK؟

1. ارفع جميع **محتويات** هذا المجلد إلى جذر مستودع `ALI-KI/Quran_Madina-V1`، مع الاحتفاظ بمجلد `.github/workflows/`؛ لا ترفع ملف ZIP نفسه فقط.
2. إذا كنت أعددت GitHub Secrets لمفتاح الإصدار الدائم قبل ذلك، **لا تغيّرها ولا تنشئ Keystore آخر**. المطلوب: `QURAN_KEYSTORE_BASE64`, `QURAN_STORE_PASSWORD`, `QURAN_KEY_ALIAS`, `QURAN_KEY_PASSWORD`، والمتغير `QURAN_SIGNING_CERT_SHA256`.
3. في تبويب Actions شغّل Workflow باسم **Build Quran Android signed APK (original Mushaf)**. في المرة الأولى، يُنزّل 604 ملف AI، ثم يحوّلها إلى صفحات WebP ويضعها **داخل APK**، ويختبر وجودها كلها، ثم يبني Release بالمفتاح الحالي ويتحقق من بصمته.
4. عند النجاح، افتح قسم Artifacts ونزّل `MadinaQuran-OriginalMushaf-signed-APK`؛ ستجد بداخله `app-release.apk`، ويمكن تحديث النسخة المثبتة ذات التوقيع نفسه.
5. إذا فشل تنزيل/تحويل صفحة أو فشل التوقيع، **يتوقف البناء ولا يُرفع APK ناقص أو موقّع بمفتاح آخر**. راجع سجل أول خطوة فشلت.

## ملفات مهمة

- `app/src/main/assets/app.js` — محرك التنقل والمصحف الثابت وواجهة القراء.
- `tools/prepare_mushaf_pages.py` — تحويل ملفات AI إلى WebP **دون إعادة صف الحروف**.
- `tools/check_mushaf_pages.py` — منع إصدار APK من دون 604 صفحة فعلية.
- `.github/workflows/build-apk.yml` — تنزيل المصدر، التحويل، الاختبار، إنشاء Release APK، والتحقق من توقيعه.
- `SIGNING_SETUP_AR.md` — استخدام مفتاح توقيع واحد ثابت بدل مفاتيح Debug.
- `QA_RESULTS_v0.7.md` — الاختبارات التي أجريت بالفعل والحدود الصريحة لها.

## حدود هذه الحزمة

هذا **مشروع مصدر أندرويد كامل** ومُعدّ لتوليد صفحاته الرسمية أثناء GitHub Actions، وليس ملف APK ولا حزمة تحتوي على صفحات الصور الـ604 مسبقًا. تعذّر تنزيل ملفات المصدر المتجهية إلى بيئة العمل الحالية، لذلك لم يحدث اختبار تحويل فعلي أو إصدار APK هنا. يجب أن ينجح إجراء GitHub Actions ويُفحص ناتجه على الجهاز قبل وصف التطبيق بأنه جاهز للنشر. إن فتحت ملف HTML منفردًا من دون الصور المولَّدة فلن نعرض لك نصًا عشوائي التبرير بدل المصحف؛ ستظهر رسالة توضح أن مصادر الصفحات غير مضمَّنة بعد.
