# مصحف المدينة الذكي — تصحيح فشل البناء v0.8.1

**تصميم وتطوير: م. محمود الجمصي — Mahmoud Elgamsy**

كان فحص v0.8 يقارن حدود صفحات مصحف المدينة المتجهي بحدود صفحات بيانات إضافية مأخوذة من مصدر آخر. ظهر الفارق في الصفحة 120: حدود البيانات الإضافية المائدة 71–76، بينما الأصل المتجهي 71–77. الآية (5:77) ليست خطأ؛ أصل صفحة 121 يبدأ بالآية (5:78).

### ما تغيّر
- استخراج خريطة الصفحات آليًا من نفس SVG الأصلي؛ لا تعديل على حروف الآيات أو شكلها.
- فحص أرقام 6236 آية على الـ604 صفحة والتحقق من عدم وجود فقد أو آيات دخيلة أو فجوات.
- استخدام خريطة المصدر للمس الآية والتنقل والبحث، بدل المقارنة مع حدود مصدر مختلف.
- تحديث كاش GitHub Actions لمنع إعادة استخدام ملفات المرحلة السابقة.

### طريقة التطبيق
ارفع ملفات المشروع الموجود داخل هذه الحزمة إلى جذر مستودع `ALI-KI/Quran_Madina-V1` مع استبدال الملفات القديمة، أو استبدل الملفات الخمسة الموضحة في `FIX_v0.8.1_README_AR.txt`. التشغيل يبدأ تلقائيًا بعد Commit، أو شغّل Workflow يدويًا. مفتاح التوقيع القديم وGitHub Secrets لا يتغيران.

**مهم:** الاختبار الكامل بملفات الـSVG الحقيقية وبناء APK يحتاجان GitHub Actions؛ جرى محليًا اختبار تدفق كامل بصفحات اختبارية وأُثبت الفشل عند فساد خريطة الآيات. لا تنشر الإصدار للعامة قبل مراجعة المطابقة النهائية.
