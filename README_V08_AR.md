# مصحف المدينة الذكي — v0.8 (الصفحة الأصلية مع لمس الآيات)

**تصميم وتطوير: م. محمود الجمصي — Mahmoud Elgamsy**  
**بريد التواصل:** mobd3on@gmail.com

## الإصلاح الوحيد المطلوب في هذا الإصدار

- **بدل صورة PDF محاطة بمساحات بيضاء:** يستخدم التطبيق صفحات SVG المتجهية من مصحف مجمع الملك فهد (حفص) بحدود محتوى مناسبة للعرض المحمول، داخل الإطار الإسلامي السابق. صفحة المصحف ليست نص HTML ولا إعادة توزيع للأسطر.
- **بدل قائمة «اختر آية»:** كل آية لها مضلع شفاف من نفس مصدر الرسوم، مضلع يحمل `surah` و`ayah`، وعند لمسه تفتح خيارات الاستماع والعلامة والنسخ والتكرار. يتيح المشغل تمييز الآية الحالية دون التغيير في الآيات الأصلية.
- لا تظهر قائمة آيات الصفحة كبديل عن اللمس المباشر.
- الاحتفاظ بالفهرس والتلاوة والقرّاء الثمانية، العلامات المرجعية، تنقل الصفحات، الوضع الليلي، وشريط التنقل السفلي.

## المصدر

- [Quran SVG — quran-ws/quran-svg](https://github.com/quran-ws/quran-svg)؛ مجموعة **`mushafs/hafs/kfqc/svg/001.svg`** إلى **`604.svg`**.
- يُستخدم **Commit** مثبت: `b4155f07e4aea087d2c458069acff9f7c7e749f6`.
- [المصدر المطبوع الأصلي / المجمع](https://dm.qurancomplex.gov.sa/)؛ للاستخدام الرقمي وفق شروط المجمع.
- خريطة الضغط على الآيات تابعة لمشروع Quran.ws وترخيصها CC BY 4.0 مع إعفاء من نسبة المصدر داخل المنتج (راجع `SOURCE_NOTICE_INTERACTIVE_MUSHAF.md`).
- **هذه الملفات ليست صورًا مولّدة بالذكاء الاصطناعي**؛ الخطوط ومناطق تحديد الآيات محفوظة داخل نفس SVG.

## كيف يعمل GitHub Actions

1. يحاول استخدام كاش SVG للصفحات الـ604.
2. إن لم يتوفر الكاش، ينزّل مستودع المصدر **sparse** لمسار حفص فقط، ويتأكد من رقم Commit.
3. يفحص كل صفحة SVG مقابل بيانات الآيات المحلية **(604 صفحة، 6236 آية، بلا تكرار أو فقد)**، ثم يضعها في `app/src/main/assets/mushaf-svg/`.
4. يبني `assembleRelease` من **نفس GitHub Secrets وكلمة المرور وشهادة التوقيع** دون توليد أي JKS جديد.
5. يتحقق من بصمة شهادة APK بالمقارنة مع `QURAN_SIGNING_CERT_SHA256`، ثم ينشر Artifact.

### تعليمات التحديث

- ارفع كل محتويات هذه الحزمة إلى **جذر** المستودع: `.github/`, `app/`, `tools/`, ملفات Gradle... إلخ.
- **لا تنشر أو ترفع `madina-release.jks` مطلقًا**. المفتاح محفوظ شخصيًا، والمستودع يستخدم Secrets الحالية فقط.
- شغّل **Actions → Build Quran Android signed APK (interactive Mushaf)**.
- تنزيل `MadinaQuran-InteractiveMushaf-signed-APK` عند نجاح Workflow.

## ما اختُبر وما لم يُختبر

- اختبار بناء JS والصيغة، حفظ الثوابت، ضغط الآية مباشرة داخل SVG تجريبي له خريطة مطابقة، إبراز الآية المختارة في الواجهة.
- ملفات المصحف الأصلية الـ604 **لا تُضمَّن مسبقًا في ZIP**؛ يتم تنزيلها والتحقق منها على GitHub Actions. لذلك لا يوجد APK مُختبر في هذه الحزمة، ولا شهادة مطابقة مستقلة لكل موضع آية في الصفحات الأصلية.
- اختبار SVG تفاعلي ببيانات تجريبية لا يعني اختبار الحروف القرآنية نفسها؛ مصدرها الأصلي يُجلب أثناء CI.
- مطلوب اختبار سرعة العرض واللمس والأصوات على هاتف حقيقي بعد البناء.
